# Replication package of "Systematic Detection of Energy Regressions in Software Version Histories"

This upload includes the energy measurements results collected using the EnergyTrackr pipeline, supporting the paper **Systematic Detection of Energy Regressions in Software Version Histories**, submitted to the Green Software Evolution special issue of the _Information and Software Technology_ journal. The dataset aims to facilitate reproducibility and future research on energy-aware software development and the identification of energy regressions.

The analysis covers 5 projects: _Classgraph_, _Fastexcel_, _Maker_, _Modelmapper_ and _Simple-OpenAI_. Each project directory contains the configuration files used for both algorithms, along with two subdirectories: _dichotomous-data_ and _naive-data_. These subdirectories include all generated data obtained through the respective algorithms. Each subdirectory contains 4 files: a CSV file with raw data, a CSV file with sorted raw data, an HTML file generated by EnergyTrackr, and a log file containing all execution logs.
